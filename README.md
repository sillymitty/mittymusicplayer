## What is MMplayer?

Its a fork of Riff v42.3 by rootless and its an UI rework + QoL project

MMplayer has all features from Riff v42.3 + more to come

## Download and install

Install it at [Releases page]([https://github.com/rootscripts/riff/releases](https://github.com/sillymitty/mittymusicplayer/edit/main/releases)).

Releases already include everything Riff needs (yt-dlp and ffmpeg are bundled), so there's nothing extra to install on Windows or Linux.

## Build from source

You need Node.js 18 or newer and npm. yt-dlp and ffmpeg are installed by default in dev and compiled into releases.

```bash
git clone https://github.com/sillymitty/mittymusicplayer.git
cd riff
npm install
npm start        # run the dev version
npm run dist     # make a production build
```

The exact build output depends on the current project configuration.

## FAQ

**Is MMPlayer free?**
Free and open source licensed with MIT

**Does Riff have ads?**
No.

**Do I need an account to use Riff?**
No.

**Which platforms does MMPlayer support?**
Windows, Linux and macOS. macOS is in beta.

**Can MMPlayer play local files?**
Yes.

**Can I use MMplayer offline?**
Yes.

**Can I import my Spotify playlists?**
Public Spotify playlists, yes, including ones with more than 100 tracks.

**Does MMPlayer support synced lyrics?**
Yes.

**Does MMPlayer work with Discord?**
Yes.

**Is there a MMPlayer app for Android or iOS?**
Not yet.
